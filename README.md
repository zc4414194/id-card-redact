## 💡 The Problem

When applying for apartment leases, bank KYC verifications, or job applications, you are often asked to provide a photo of your driver license, passport, or utility bill.

However, once sent, your unmasked ID card can be:
- Intercepted by malicious actors.
- Used to open unauthorized credit accounts or fraudulent SIM cards.
- Leaked during third-party corporate data breaches.

**ID Card Redact** solves this by letting you add tamper-resistant security watermarks (e.g., *"FOR RENTAL APPLICATION ONLY - VOID FOR LOANS"*) and black out / blur sensitive numbers right inside your browser before sending.

---

## ✨ Features

- **🔒 100% Offline & Private:** Runs entirely locally inside your browser with HTML5 Canvas. Your sensitive identity documents are never sent over the internet.
- **🛡️ Anti-Misuse Security Watermark Presets:**
  - `FOR IDENTITY VERIFICATION ONLY - VOID FOR ANY OTHER PURPOSE`
  - `FOR RENTAL LEASE APPLICATION ONLY - VOID FOR LOAN/CREDIT`
  - `SAMPLE ONLY - NOT FOR OFFICIAL USE`
  - `FOR VISA / PASSPORT APPLICATION ONLY`
  - Full support for custom security text.
- **⬛ Sensitive Info Redaction:** Click and drag to create opaque black bars, pixelated mosaics, or Gaussian blurs over ID numbers, birthdays, and signatures.
- **🎛️ Watermark Fine-Tuning:** Customize repeating watermark density, rotation angle, and opacity so the text protects the document without obscuring required details.
- **📋 One-Click Copy & Download:** Export high-resolution protected PNGs or copy directly to your clipboard for instant pasting.

## 🚀 Quick Start (Run Locally)

No installation, build step, or server needed!

1. Clone or download this repo:
   ```bash
   git clone https://github.com/your-github-username/id-card-redact.git
   cd id-card-redact
   ```
2. Double-click `index.html` in your browser.
3. You're done!

## 📦 Deploy on GitHub Pages (Free Hosting)

1. Create a new public repository on GitHub (e.g., `id-card-redact`).
2. Push `index.html` and `README.md` to `main`.
3. In your repo, go to **Settings** → **Pages**.
4. Select branch `main` and root `/`, then save.
5. Your live tool is instantly available at `https://<your-username>.github.io/id-card-redact/`.
